# BMW F07 Launcher

BMW F07 2016 530d xDrive 5GT + MEKEDE MN-L (Android 14, 2560×720 울트라와이드) 전용
개인용 홈 런처입니다. Kotlin + Android SDK만 사용하며 네이티브 라이브러리(.so)가 없어
ARM64 실기기와 x86_64 에뮬레이터(LD플레이어 등) 모두에서 설치·실행됩니다.
(최소 지원 Android 8.0 / API 26 — 에뮬레이터에서도 설치됩니다.)

## 기능

- **완전 직사각 · 올블랙 UI**: 모든 모서리 반경 0dp, 배경 `#000000`, BMW M 색상의 얇은 포인트 라인.
- **자유 분할 (5:5 ~ 2:8, 좌우 반전 포함)**: 중앙 디바이더 드래그 + 빠른 비율 버튼 7종
  (`5:5`, `6:4`, `7:3`, `8:2`, `4:6`, `3:7`, `2:8`), 좌우 스왑, 한쪽 창 전체화면 토글.
- **창별 독립 DPI (120~480)**: 가상 디스플레이 모드에서 왼쪽/오른쪽 창의 밀도를 따로 지정해
  2:8 같은 좁은 창에서도 앱 UI가 잘리지 않게 합니다.
- **두 가지 실행 엔진** (설정에서 선택)
  1. `시스템 분할/자유 창` — `ActivityOptions.setLaunchBounds` + 접근성 서비스로 앱을 지정 위치에 띄웁니다.
  2. `가상 디스플레이` — `VirtualDisplay` + `SurfaceView`로 런처 프레임 안에 앱을 직접 렌더링합니다. (펌웨어 지원 필요)
- **기본 프리셋 6종**: 네이버지도·티맵 × FLO·QQ MUSIC·YouTube ReVanced. 실제 패키지를 자동 매칭하고,
  독을 길게 누르면 설치된 앱 목록에서 직접 재지정할 수 있습니다.
- **전체 앱 서랍**: 그리드, 앱 숨기기, 왼쪽/오른쪽/전체화면으로 바로 열기.
- **BMW M 인트로**: 기본 내장 M 스트라이프 애니메이션 또는 사용자가 고른 `.mp4`를 전체 화면으로 재생,
  터치로 즉시 스킵, 홈 복귀 시 건너뛰기 옵션.
- **독**: 하단/좌측 위치, 자동 숨김, 시계·날짜, 앱 서랍·설정 버튼.

## 빌드 (GitHub Actions, 권장)

1. GitHub 저장소 → **Actions** → **Build BMW F07 Launcher APK** → **Run workflow**.
2. 워크플로 파일이 없다면 저장소 루트에 `.github/workflows/build.yml`을 만들고
   이 저장소 루트의 `GITHUB_ACTIONS_BUILD.yml` 내용을 그대로 붙여 넣습니다.
3. 빌드가 끝나면 `bmw-f07-launcher-debug` 아티팩트에서 APK를 내려받아 설치합니다.

로컬 빌드: JDK 17 + Android SDK 34가 있으면 `gradle assembleDebug`.

## 첫 실행 설정

1. 설정(⚙) → **기본 런처로 설정**에서 이 앱을 홈으로 지정합니다.
2. 분할 방식 선택
   - `시스템 분할`을 쓰려면 **접근성 서비스 켜기**를 눌러 서비스를 켭니다.
     자유 형식 창이 꺼져 있는 기기에서는 개발자 옵션의 `자유 형식 창`(freeform)을 켜면 2:8 비율까지 적용됩니다.
   - `가상 디스플레이`를 쓰려면 **오버레이 권한 허용**을 눌러 권한을 줍니다.
3. 독의 프리셋을 길게 눌러 앱이 실제로 설치되어 있는지 확인합니다(미설치 앱은 흐리게 표시).

## 알려진 제약

- 가상 디스플레이 모드는 Android가 서드파티 앱에 공개 가상 화면 생성을 허용해야 동작합니다.
  막혀 있으면 안내 후 시스템 분할 모드로 사용해야 하며, 이 경우 앱 자체 DPI는 바꿀 수 없습니다.
- YouTube ReVanced는 패키지명에 `revanced`가 들어간 앱을 자동으로 찾습니다.
